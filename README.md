# ⏱️ Chronos Pomodoro

Uma aplicação simples de **Pomodoro Timer** para ajudar a manter o foco e organizar o tempo.

---

## 🚧 Status do Projeto

⚠️ Este software ainda está em desenvolvimento.  
Funcionalidades podem estar incompletas, sofrer mudanças ou apresentar bugs.

---

## 📌 Sobre o Projeto

O **Chronos Pomodoro** é uma ferramenta baseada na técnica Pomodoro, que divide o tempo em ciclos de foco e descanso para melhorar a produtividade.

---

## 🚀 Funcionalidades

- ⏳ Timer de foco (Pomodoro)
- ☕ Pausas curtas e longas
- ⚙️ Configuração de tempo personalizada *(em desenvolvimento)*
- 🔄 Ciclos automáticos *(em desenvolvimento)*

---

## 🛠️ Tecnologias Utilizadas

- React
- JavaScript
- HTML + CSS
